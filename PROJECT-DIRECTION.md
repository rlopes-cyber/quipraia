# Direcionamento atual do projeto

## Momento

O próximo ciclo é de naming, branding e layout. A programação da versão de produção será feita depois, no Claude, usando este direcionamento como base.

## Produto

- Plataforma web mobile-first para leitura de condições de surf.
- Começo em Salvador, com expansão para outras cidades.
- Informações: ondas, período, direção, vento, maré, mapa, fotos, relatos e comparação entre praias.
- Interação entre surfistas com relatos, confirmações, favoritos e histórico.
- Plano gratuito com anúncios e plano Colaborador posteriormente.
- Sem Apple Login.
- Login desejado: Google e, se necessário, e-mail.
- Banco de dados real desde o início para permitir interação entre usuários.

## Tecnologia direcionada

- Supabase para Auth, PostgreSQL, Row Level Security e Realtime.
- Google OAuth via Supabase Auth.
- Open-Meteo Weather e Marine para o primeiro teste gratuito.
- MapLibre/OpenStreetMap para mapa sem dependência inicial do Google Maps.
- Maré deve ser identificada como previsão/modelo até existir uma fonte oficial integrada.

## Escopo inicial

- Salvador como cidade-piloto.
- Praias já consideradas: Stella Maris, Praia do Flamengo, Itapuã, Jaguaribe, Buracão, Farol da Barra, Porto da Barra, Piatã e Patamares.
- Usuários devem conseguir criar perfil, salvar praias, publicar relatos e confirmar relatos de outros usuários.
- Administração deve permitir moderar relatos, editar praias e acompanhar fontes.

## Marca

- O nome aprovado para direção criativa é SurfCrew; a validação jurídica e de disponibilidade ainda está pendente.
- Procurar um nome curto, fácil de falar e memorizar, ligado diretamente a surf, ondas, mar ou leitura das condições.
- O nome precisa permitir expansão para outras cidades e países.
- A marca deve comunicar surf de forma evidente, sem parecer apenas um app meteorológico.
- O branding deve ter personalidade, fotografia de mar, tipografia surfista controlada, ícones coerentes e linguagem de comunidade.
- Não usar nome final antes de pesquisar domínio, redes sociais e registros de marca.

## Critérios para o novo nome

1. Explica ou sugere rapidamente o que o produto faz.
2. É curto e pronunciável em português.
3. Tem potencial de marca e identidade visual.
4. Não limita o produto a Salvador.
5. Não parece nome genérico de previsão do tempo.
6. Deve permitir pesquisa posterior de domínio, INPI, redes sociais e conflito com marcas existentes.
